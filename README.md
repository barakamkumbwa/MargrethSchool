# 🎓 Margreth Pre & Primary School Website

A modern, responsive, and professional school website for **Margreth Pre & Primary School** — built with pure HTML, CSS, and vanilla JavaScript.

Tovuti ya kisasa ya shule ya **Margreth Pre & Primary School** — iliyoundwa kwa kutumia HTML, CSS, na JavaScript safi (bila framework).

## ✨ Features / Vipengele

### 🌍 Core Features
- ✅ **Fully Responsive** — Inafanya kazi kwenye simu, tablet, na kompyuta
- ✅ **Modern UI/UX** — Design ya kisasa, safi, na ya kuvutia
- ✅ **Auto-Rotating Gallery** — Picha za gallery zinajibadilisha zenyewe
- ✅ **Masonry Gallery Layout** — Picha zinajipanga kwa mtindo wa kupishana
- ✅ **Progress Timeline** — Hatua za udahili zinaonekana kama timeline
- ✅ **Accordion Sections** — Sehemu zinazofunguka na kufunga
- ✅ **Marquee Banner** — Maandishi yanayotembea kwenye banner
- ✅ **PDF Form Download** — Fomu ya kuomba inaweza kudownload kama PDF
- ✅ **News & Events System** — Kurasa za habari na matukio
- ✅ **Contact Form** — Fomu ya kuwasiliana
- ✅ **Google Maps Integration** — Ramani ya shule

### 🎯 Design Features
- Smooth animations & transitions
- Hover effects kwenye cards na buttons
- Custom color palette (bluu & njano)
- Font Awesome icons
- Gradient backgrounds
- Card-based layouts

## 🛠️ Tech Stack / Teknolojia Iliyotumika

| Teknolojia | Matumizi |
|------------|----------|
| **HTML5** | Muundo wa kurasa (semantic markup) |
| **CSS3** | Design, layout, animations (Grid, Flexbox) |
| **JavaScript (Vanilla)** | Interactivity (accordion, slideshow, filters) |
| **Font Awesome 6** | Icons (free version) |
| **Google Maps Embed** | Ramani ya shule |

**Hakuna frameworks** kama React, Vue, au Bootstrap — ni **pure HTML, CSS, na JS**.
